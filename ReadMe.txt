Rice Frequency Mapping: Source Code

This repository contains scripts and workflows for mapping rice cropping frequency across South Asia using multi-temporal Sentinel-1 and Sentinel-2 satellite imagery within the cloud-based geospatial processing platform Google Earth Engine (GEE). The outputs include high-resolution (10 m) annual rice cropping frequency maps, enabling the identification of single-, double-, and triple-cropping rice systems.

These maps support food security assessment, agricultural monitoring, and climate-related research by providing consistent, open-access, and reproducible datasets.
